Zombie Apocalypse – model layout (like reference server)
========================================================

  zombie_apocalypse/
  ├── weapons/     ← All custom weapon models (v_*, p_*, w_*, effects)
  │                 Thanatos, Cannon, Dread Nova, Balrog, Skull, GunGnir,
  │                 Crow9, Laser MG, Dual Uzi, Thunder Pistol, etc.
  └── *.mdl       ← ZP claws, knives, supplybox, bat, zombie effects
                    (from former zombie_plague + flying zombi)

Scripts reference:
  models/zombie_apocalypse/weapons/<name>.mdl
  models/zombie_apocalypse/<name>.mdl

Sounds: keep using sound/weapons/, sound/zombie_plague/, sound/prestige_abilities/
or create sound/zombie_apocalypse/ and point config/menus there if you want the same order.
