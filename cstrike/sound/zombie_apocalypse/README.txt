Zombie Apocalypse – sound folder (optional)
===========================================
You can move ZP-related sounds here (e.g. from zombie_plague/, prestige_abilities/, or weapon subfolders) to match the reference server layout. Update zombieplague.ini and any plugin paths that reference those sounds.
Current scripts use: sound/weapons/, sound/zombie_plague/, sound/prestige_abilities/ – change those to sound/zombie_apocalypse/ if you move files here.
